# 🔠 ConvertText — Text Converter Utility Web App

**ConvertText** is a simple yet powerful text utility tool built using **React.js**.  
It helps users quickly manipulate and analyze text — ideal for writers, students, developers, and anyone working with content.

🌐 **Live Demo**: [Try ConvertText](https://convert-text-word-counter-and-characters-counter-case-converter.vercel.app/)  
(Replace with your deployed URL if live)

---

## 💡 Features

- 🔡 **Convert to UPPERCASE / lowercase**
- ✂️ **Trim extra/unwanted spaces**
- 🔢 **Word & Character Count**
- ⏱️ **Instant preview & live conversion**
- 🧼 **Clear Text with one click**
- 🧪 Fully reactive and component-based
